# ejson

[![XERJ Corpus Hub contributor](https://hub.xerj.org/contributors/SkyOrang/badge.svg)](https://hub.xerj.org/contributors/SkyOrang)

Based on the C/C++ standard library, programmers can directly perform common operations such as adding, deleting, querying, and modifying various fields in JSON files within text streams.

For detailed instructions, please refer to the Wiki.

**Usage Notes**

ejson is not a general-purpose JSON parser like nlohmann. ejson is designed for rapid construction and manipulation of JSON data.

**Features**

- Interface-driven design to simplify operations and enhance efficiency (based on operator overloading for [], <<, >>)
- Excellent build performance
- Cross-platform support (based on the C/C++ standard library)
